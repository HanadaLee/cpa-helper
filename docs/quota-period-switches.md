# 日配额与周配额开关

从 0.3.23.128 起，用户管理中的日配额、周配额可以分别启用或关闭：

- 开启：按该周期金额限制基础配额；金额为 0 时，该周期没有可用基础配额，但仍可使用有效额度卡。
- 关闭：不限制该周期。只开启周配额时，当前可用余额为周剩余配额加有效额度卡；只开启日配额时同理。两项都开启时仍取两项剩余配额中的较小值，再加有效额度卡。
- 两项都关闭：明确允许无限额用量，不扣额度卡。

额度卡和基础配额仍按到期时间抵扣。只有周配额开启时，基础配额的到期时间为北京时间下周一 0 点，不再误按每天 0 点排序。开关切换不会清零已用量或改变周期；清零仍需单独的重置操作。

接口继续使用现有可空金额字段：`daily_quota_usd: null` 表示关闭日配额，`weekly_quota_usd: null` 表示关闭周配额；数字 0 不等同于关闭。管理员更新接口为 PUT，需明确提交这两个字段。

新用户出厂默认保持限制启用、周配额金额为 0；没有额度卡时不可使用。既有管理员显式配置的新用户默认策略仍生效。升级不改写任何现有用户的配额、余额、已用量或开关，也不把历史数值 0 自动转换为无限额。

本次无数据库结构迁移。需要仅使用周配额的现有用户，请由管理员在用户管理中关闭日配额、保留周配额并保存。旧版本不支持单周期关闭，出现部分周期为 null 的用户后，不应直接回退旧程序而不核对配额语义。

管理员与普通用户的“我的用量”共用同一页面与货币图标。余额徽标橙色表示历史未定价记录或密钥同步异常，红色表示余额暂停，颜色不由管理员身份决定；悬停可查看原因。
